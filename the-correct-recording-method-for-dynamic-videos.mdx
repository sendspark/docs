To record correctly for a Dynamic Video, set the recording mode to **Camera Only** in the Sendspark Chrome extension. The default is **Cam + Screen**, which records your face along with your screen. That's ideal for standard videos, but it produces an unwanted result in a Dynamic Video. Switch to Camera Only using the icons at the bottom of the recorder before you record.

## Key takeaways

- Use the **Camera Only** recording mode for Dynamic Videos, set from the bottom icons in the Sendspark Chrome extension.
- The default is **Cam + Screen**, which records your face along with your website or screen. The active mode appears darker than the others.
- Cam + Screen is the best mode for regular videos, but using a Cam + Screen recording in a Dynamic Video gives an unwanted result.
- Set the mode to Camera Only *before* recording, so your Dynamic Video displays as intended.

The first step towards recording your first videos is to click on the Sendspark Chrome extension icon. Doing that will open your camera's feed in a bubble on top of your background, just like this:

![Sendspark Chrome extension camera bubble overlay displaying user face on website](/images/9565499/9a542bc6-image.png)

That's the default mode, **Cam + Screen**, and it's the best way to record yourself along with your website. You can change it from the bottom icons:

![Sendspark recording mode icons at the bottom of the recorder, with the active mode shown darker](/images/9565499/8c88842f-image.png)

You'll notice the active option is darker than the rest, showing which mode is currently selected.

To record a Dynamic Video correctly, set the mode to **Camera Only**.

Recording in Cam + Screen and using that video in a Dynamic Video will give an unwanted result:

![Dynamic Video showing the unwanted result of using a Cam + Screen recording](/images/9565499/06d8a3c4-image.png)

## Why not use Cam + Screen for Dynamic Videos?

Cam + Screen records your face and your screen at the same time, which is ideal for standard videos. But a Dynamic Video is designed to place just your face over a personalized background. When a Cam + Screen recording is used in one, you end up with a screen inside a screen rather than a clean camera bubble. Recording in Camera Only keeps just your face, so it sits correctly on the dynamic background. For a deeper comparison, see [Camera Only vs Cam + Screen recording in Dynamic Videos](/face-recording-vs-both-recording-in-dynamic-videos).
